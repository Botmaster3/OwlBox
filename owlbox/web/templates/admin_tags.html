Eltern-Chips

Chips für Vater/Mutter/etc.: beim Auflegen loggt sich die Verwaltung ein und die Box zeigt auf ihrem Display einen QR-Code zur Login-Seite an - so können sich Eltern per Handy einloggen, ohne dass Kinder je den QR-Code oder die Login-Seite zu Gesicht bekommen.

Neuen Eltern-Chip anlegen

Freier Name zur Wiedererkennung in der Liste oben - hat keine Auswirkung auf die Funktion des Chips.

Startet den Scan-Modus - der nächste erkannte Chip wird als Eltern-Chip gespeichert: beim Auflegen loggt er automatisch in die Verwaltung ein und zeigt auf dem Kiosk-Display einen QR-Code zur Login-Seite.

Funktions-Chips

Chips, die beim Auflegen eine Aktion auslösen statt eine Geschichte abzuspielen - z.B. eine eigene Karte für Play/Pause, Lautstärke oder WLAN.

Neuen Funktions-Chip anlegen

Legt fest, welche Aktion der neue Chip beim Auflegen auslöst - statt eine Geschichte abzuspielen. Shuffle- und Wiederholungs-Aktionen schalten bei jedem erneuten Auflegen desselben Chips zwischen an und aus um, statt eine Geschichte zu starten.

Startet den Scan-Modus für die oben gewählte Aktion.
