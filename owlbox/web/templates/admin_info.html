    Wartung

    Datenbank + alle Medien als ZIP herunterladen - die einzige Möglichkeit, die Bibliothek wiederherzustellen, falls die SD-Karte einmal ausfällt.

    💾 Backup herunterladen

    Lädt eine ZIP-Datei mit Datenbank und allen Mediendateien herunter - verändert nichts auf dem Gerät selbst.

    Prüft beim Laden dieser Seite automatisch, ob eine neuere Version im Repository verfügbar ist - gefunden wird nur geprüft, installiert wird ausschließlich nach deiner Bestätigung.

    Prüfe auf Updates…

    Die Installation holt den neuesten Stand per git pull, installiert ggf. neue Abhängigkeiten und startet den OwlBox-Dienst neu (nicht den ganzen Pi) - die Wiedergabe wird dabei kurz unterbrochen, die gespeicherte Position bleibt erhalten.

    Dokumentation

    Installationsanleitung vom leeren Pi bis zur laufenden Box, Schnellstart für den ersten Start, die vollständige Bedienungsanleitung mit jedem Regler im Detail, sowie die komplette Verkabelungs-Referenz für den Hardwareaufbau.
