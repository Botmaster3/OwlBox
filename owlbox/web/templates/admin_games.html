Bilder (Memory & Schiebe-Puzzle)

Diese Bilder werden von zwei Mini-Spielen gemeinsam genutzt: beim Memory-Spiel als Paare (je zwei Karten pro Bild, gemischt), beim Schiebe-Puzzle wird jeweils ein zufälliges Bild in Teile zerlegt. Mindestens 2 Bilder nötig, damit Memory überhaupt ein Paar zum Finden hat; mehr als 12 werden für eine Memory-Runde nicht gebraucht (der Rest bleibt trotzdem in der Sammlung und kann bei der nächsten Runde oder für das Puzzle mit dabei sein).

Noch keine Bilder hochgeladen.

Klänge (Sound-Memory)

Kurze Klangschnipsel für das Sound-Memory-Spiel - statt Bildpaaren werden hier Klangpaare per Gehör gesucht: Karte antippen spielt den Klang ab, die zweite Karte mit demselben Klang finden. Mindestens 2 Klänge nötig.

Noch keine Klänge hochgeladen.

Rätsel (Tier-Sound-Quiz)

Bild+Ton-Paare für das Tier-Sound-Quiz - z.B. ein Kuh-Foto plus eine Muh-Aufnahme. Ein Klang spielt ab, das Kind tippt aus mehreren Bildern das passende an. Die Bezeichnung ist optional und nur zur eigenen Übersicht hier - sie wird im Spiel selbst nie angezeigt. Mindestens 2 Rätsel nötig, damit es überhaupt eine falsche Auswahlmöglichkeit gibt.

Noch keine Rätsel angelegt.

Aktivierung per RFID-Chip oder Button

Die Mini-Spiele werden nicht hier gestartet, sondern entweder über einen dafür angelegten Funktions-Chip (unter „RFID-Tags“ einen Chip mit der Aktion „Spiele-Menü an/aus“ anlegen) oder über den „🎮 Spiele-Menü öffnen“-Button auf der Home-Seite. Beides schaltet das Kiosk-Display auf das Spiele-Menü um (dort ist dann auch als einzige Stelle in OwlBox der Touchscreen aktiv) - von dort lässt sich eines der Mini-Spiele antippen. Erneutes Auslösen (Chip nochmal auflegen oder Button nochmal klicken) verlässt das Spiele-Menü wieder komplett und zeigt wieder die normale „Jetzt läuft“-Ansicht. Eine laufende Geschichte spielt im Hintergrund einfach weiter.
